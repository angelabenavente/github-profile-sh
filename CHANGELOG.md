# Changelog

## 0.1.0

- Initial public release of github-profile.sh.
- CLI `github-profile-sh init` writes config and a GitHub Actions workflow.
- Action generates an animated terminal SVG from public GitHub profile data.
- Metrics: public repos, stars, current streak, code changes, top languages.
- Animation modes: typing, sequential, and static (`none`).
- Update frequencies: 12h, daily, weekly, monthly, and manual.
