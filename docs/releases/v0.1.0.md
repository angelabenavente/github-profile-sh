# v0.1.0

First public release of github-profile.sh.

Animated GitHub profile stats rendered as a terminal, generated by GitHub
Actions. There is no hosted backend.

## Highlights

- Public metrics: repositories, stars, current contribution streak, code
  changes, and top languages
- Terminal-style SVG with typing, sequential, or static rendering
- Interactive CLI setup (`npx github-profile-sh init`)
- Generated workflow that updates `github-profile.svg` on a schedule or
  manually
- GitHub Action at `angelabenavente/github-profile-sh@v1` (create the
  movable `v1` tag after this release; see `docs/releasing.md`)

## Installation

From a public GitHub Profile README repository:

```bash
npx github-profile-sh init
```

Add this to the profile `README.md`:

```md
![github-profile.sh](./github-profile.svg)
```

Requires Node.js 24+ only if you run the CLI locally. The Action uses
Node 24 on GitHub-hosted runners.

## Notes

- Only public GitHub data is used. Private repositories are not included.
- Repos and stars count every public repository you own, including forks.
- Code changes may be shown as an approximation (`~8.4k`) when GitHub
  contributor stats are incomplete.
- The SVG is generated in the repository. Viewing the README does not
  regenerate it.
- Software is MIT. Generated SVGs are CC BY 4.0 and include an attribution
  comment pointing at the original repository.
